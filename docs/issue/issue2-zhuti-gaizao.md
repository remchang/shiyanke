## 用户故事
作为访客，我希望博客的导航、文章列表和详情页比默认主题更符合中文阅读习惯，能直接看到文章属于哪个标签、大概要读多久。

## 改造范围（修改边界：只改主题，不动 Ghost 核心）
- [ ] 顶部导航：改成中文导航（首页、标签、关于、搜索）
- [ ] 文章卡片：卡片上显示标签、阅读时长、字数
- [ ] 文章详情：标题下显示作者、发布日期、阅读时长、字数、标签列表
- [ ] 窄屏（手机宽度）下导航和卡片不溢出
- [ ] 主题通过 gscan 校验，无 fatal/error

## 非目标
- 不改 Ghost 核心源码（core/ 目录一行不动）
- 不只是换颜色和 Logo，视觉调整只是附带

## 验收条件
1. 改动都能在 theme/shiyanke-theme 源码里定位到具体文件。
2. gscan 校验无 error 级别问题。
3. 桌面 1280px 和窄屏 375px 下都能正常浏览。
