## 用户故事
作为访客，我在搜索框输入中文关键词后，想看到命中的文章列表、关键词高亮、我最近搜过的词；搜不到东西时，页面不要空白，给我推荐几个标签继续逛。

## 方案选择
放在**主题层**实现，用 Ghost Content API（只读公开密钥）拉取已发布文章，在前端做匹配：
- 不放在 Ghost 核心：升级 Ghost 版本时不会被覆盖；
- 不用 Admin API：管理密钥绝不出现在浏览器里；
- 不单独起后端服务：本地实验要一键启动，不想增加部署复杂度。

## 功能点
- [ ] 关键词同时匹配标题和正文（纯文本），中文不做复杂分词，用「包含」匹配保证召回
- [ ] 结果列表中命中的关键词加 `<mark>` 高亮，转义特殊正则字符防止报错
- [ ] 最近搜索：localStorage 保存最近 8 条，可一键再搜、可清空
- [ ] 无结果：提示「没有找到相关文章」并列出全部标签做兜底入口
- [ ] 匿名用户也能搜索公开文章

## 非目标
- 不做服务端全文索引（ES 那种），不存任何访客个人信息
- 不收录未发布/会员专享文章

## 验收条件
1. 搜「开源」能命中含该词的文章并高亮。
2. 搜 `*` 这类特殊字符页面不崩溃。
3. 刷新后最近搜索还在，点「清空」能清掉。
4. 搜一个肯定不存在的词（如「鲲鹏翱九霄xyz」）出现无结果提示+标签推荐。
5. 有可重复执行的自动化测试（tests/zidong）。
